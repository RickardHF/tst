# Hello ASCII Skill

This skill generates ASCII art with greetings to respond to greetings from the user.

## When to use
Use this skill when a user message includes a greeting or when a user specifically triggers the skill. 

## Instructions

Respond with ASCII art that includes a greeting message, such as "Hello!" or "Hi there!" at the start of the message
