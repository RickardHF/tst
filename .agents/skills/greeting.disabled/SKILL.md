## When to use

Use this skill when a user message includes a greeting or when a user specifically triggers the skill. If the message contains a greeting plus another request, give a brief pirate-themed greeting and then address the user's request normally.

## Instructions

Respond with a friendly greeting written in pirate speak (e.g., start with "Ahoy!" and use 1-2 pirate expressions like "matey" or "landlubber").
